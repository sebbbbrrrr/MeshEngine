# Experimental neural reconstruction
TripoSR upstream: https://github.com/VAST-AI-Research/TripoSR (MIT; check checkpoint terms independently). Source is fetched at the pinned revision by the benchmark workflow; weights are fetched from stabilityai/TripoSR, not a hosted inference demo. No training or API subscription required.
The public CI is strictly for the synthetic generic cube fixture. Never pass private references, credentials, or MeshVault content to it. For production, install the same dependencies on an authorized private execution host and run reconstruct.py with a segmented reference on a gray background and a trusted local checkpoint. TripoSR is single-view; multiple images do not constitute joint reconstruction. Outputs are normalized STL/GLB, not dimensioned or print-certified. The report checks finite/nonempty geometry, watertightness and winding, not full printability.
The benchmark is experimental and independent of existing pedestal code. Delete this branch/close its draft PR to discard it.
